# House Price Prediction

## About the Project

This is my first machine learning project, in which I explore how Python can be used to predict house prices based on different characteristics.

I use the Boston Housing dataset and build machine learning models to understand how different factors relate to house prices and how accurately a model can make predictions.

## What I Did

- **Explored the data:** Loaded the dataset and examined the available information about houses and their surroundings.
- **Built my first model:** Used linear regression to predict house prices based on the average number of rooms.
- **Used multiple features:** Built another model using several characteristics instead of just one.
- **Measured accuracy:** Compared predictions with actual house values using MAE and RMSE.
- **Selected useful features:** Tested how using different numbers of features affects the model's performance.
- **Compared models:** Evaluated a model using all available features against one using a smaller selection.
- **Predicted individual house prices:** Used the trained model to predict a house's value and compared it with the actual value.

## Results

The model using all available features performed slightly better than the model using nine selected features on my current test dataset.

I also tested the model on an individual house. Its predicted value was approximately $29,095, compared with the actual value of $23,600.

These results helped me understand that machine learning predictions are not always exact and that models should be evaluated using more than one example.
